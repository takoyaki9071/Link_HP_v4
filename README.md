 # Link 公式ホームページ V3

公開可能な情報をもとに、公式ホームページを設計・開発するための資料です。ここに含まれる理念やサイト構成案は制作の出発点であり、公開前に団体の最新の承認内容と事実関係を確認してください。

決定事項と現状の進捗は `AGENTS.md` に逐次記録する。

## 開発環境

V3のホームはAstro（静的サイト）で実装しています。開発は `npm run dev`、検証は `npm run build` / `npm run preview` で行います。お知らせの追加は `src/content/news/` の markdown で行います（手順は [docs/更新手順.md](docs/更新手順.md)・要件定義書 §7.3）。決定事項の記録は `AGENTS.md`、要件の根拠は `docs/要件定義書.md` を参照してください。

## 公開前チェック

- 団体情報、理念、活動、実績、連携先、募集状況を関係者に確認する。
- 氏名、写真、連絡先、投稿内容の公開同意を確認する。
- 未確認・未実施の内容を、確定済みの事実や実績として掲載しない。
- フォーム、SNS、イベント情報など、掲載するリンクの公開可否と有効性を確認する。
